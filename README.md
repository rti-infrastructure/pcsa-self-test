# Philosophical Core Self-Assessment (PCSA)

Self-test for the FAA prescriptive vs. risk-based transition study.

## Event use
Host `index.html` (from the project kit `PCSA_Self_Test/web/index.html`) on GitHub Pages or any static host, then print the QR that points at that URL.

Enable Pages: Settings → Pages → Deploy from branch `main` / root. Expected URL:

https://rti-infrastructure.github.io/pcsa-self-test/

Until Pages is on, the quiz file lives in the project folder and in Moodle XML form.

## Moodle
Import `PCSA_Moodle_Question_Bank.xml` as Moodle XML into the course question bank. Build Quiz A from the short-form category (12 items). Build Quiz B from all categories (24 + 6 scenarios).

Not an FAA, certificate, or medical instrument.
